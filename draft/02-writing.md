# 第二章　文字：把经验钉在时间里

三千三百年前，安阳。一个人把一片龟腹甲钻出几个小坑，用火在坑边烧。甲面"卜"的一声裂开一道纹，他看纹路的方向和长短，判断吉凶——今天下雨吗？王去田猎，会有收获吗？今年收成如何？

然后他要在甲骨边缘刻一行字：日期、问题、结果。刻完归档。同一件事若后来应验了，有时还要补刻一句"允雨"——果然下了。

我们今天挖出来的十几万片甲骨，绝大多数是这个样子。它们不是文学，是**档案**。

## 一、文字不是为了讲故事

关于文字的起源，最容易有的误会是：文字是为了记录故事、诗歌、神话而发明的。事实基本相反。最早的成体系文字，几乎都是用来**记账**的。

在两河流域的乌鲁克（约公元前 3200 年），考古学家挖出了大量小泥板，上面是些符号和数字：几只羊、几斗大麦、谁欠谁。再往前追，还能追到更原始的"陶筹"——用不同形状的小陶块代表不同数量的牲畜和谷物，装进泥球里封起来，外面按个印，表示"这里面有七只羊"。后来人嫌麻烦，干脆把符号直接压到泥板表面上。

**从"东西"到"符号"，这一步就是文字的诞生。**

为什么是账本？因为账本最需要精确，也最不怕枯燥。羊可以数错，但税不能收错；口头约定可以赖，但写在泥板上、双方按了印的约定，赖起来就难。文字解决的第一件事，不是"我想说句漂亮话"，而是"**我要一个不会变的东西做凭据**"。

这个起点规定了文字此后几千年的主要用途：契约、税法、法典、历法、王室名录、军事记录。汉谟拉比法典刻在石柱上（约公元前 1750 年），公开立在神庙里，谁都能去看——它的功能不是文学欣赏，是**让统治规则脱离统治者的记忆，变成不依赖于人的东西**。

## 二、它做了什么：把"现在"接上"过去"

语言能谈论过去，但那个"过去"只活在说话人的记忆里，人死了就没了。文字把记忆搬到了人身之外。

这件事的后果，比"能记事"要深得多。

**第一，积累变成可能。** 口头社会里，每一代人都得从头学一遍，学不会就断。有了文字，第七代人可以在第三代人的记录上接着做，不必重新发明轮子。人类的知识第一次变成**可叠加**的东西——不是替换，是累加。

**第二，责任可以追溯。** 谁在什么时候答应了什么，白纸黑字（当时是黑泥白字）。这让"长期交易"成为可能：两个互不信任的人，可以靠一份记录跨越几年甚至几十年合作。信用从"人对人"变成了"人对文书"，这是商业的前提。

**第三，权力找到了新的载体。** 会写字的人成了稀有人才。古埃及的书吏是一个有特权的阶层，他们有专门的学校、专门的工具、专门的仕途。中国的"史"官、两河的"书吏"、玛雅的祭司，都是同一个角色：**掌握记录权的人，就掌握了定义权。** 谁的历史被写下来，谁就是正统；谁的债务没被记下来，谁就等于没欠。

**第四，思维方式被改变了。** 这一点不容易看出来，但影响极深。文字让信息可以排成**列表**——同一类东西摆在一起，逐项对照。列表是分类的前提，分类是逻辑的前提。有了列表，才有"所有 A 都是 B，这个 C 是 A，所以 C 是 B"这种推理能被执行。人类学家把这种变化称为"书写的后果"：不是人变聪明了，是**思考有了外部脚手架**。

## 三、第一代载体：什么都能写，但什么都贵

文字要有地方写。人类试过的材料，本质上是在两个指标之间做取舍：**耐久**和**便宜**。

**石头**最耐久，最贵。刻一方碑，要石匠、要工具、要几个月。所以石头只用来写最重要的东西：法典、功绩、墓志。

**甲骨**耐久，但要先找到龟甲、要整治、要钻凿、要刻。一片甲骨能写几十个字。它的问题不是不结实，是**不能量产**。

**泥板**便宜得惊人——河边有的是泥，压平就能写，写错了抹平重来。代价是重、易碎，但有个意外的好处：火烧之后会变得极硬。所以考古学家从被大火烧过的宫殿废墟里，挖出了大量完整的档案。亚述巴尼拔图书馆的两万多块泥板，就是这么留下来的。**便宜，是泥板赢的原因。**

**莎草纸**轻、便宜、能卷，是地中海世界的赢家。但它的产地集中——尼罗河三角洲，制作工艺被埃及人垄断了几千年。**被垄断的便宜，就不是真便宜。**

**羊皮纸**结实、可刮改重写，但原料是牲畜皮。一本大圣经要用两三百张羊皮，等于一个牧场几年的产出。中世纪的抄本为什么那么珍贵？不是因为字写得好，是因为**材料就是一群羊**。

这三种材料的共同困境是：**写下来容易，复制下来极难。** 你有一本书，想让第二个人也有，只能找一个人，坐下来，一个字一个字抄一遍。几个月。

这就是文字留下的窟窿：**东西存住了，但只有极少数人拿得到。**

## 钱在这一级：书吏，记录权就是定义权

文字出现之后，第一代"靠信息吃饭"的人不是作家，是**书吏**。

埃及有一份著名教学文本（《兰辛纸草》，约公元前十二世纪），内容是老师劝学生用功：你看看农夫、渔夫、工匠、石匠的日子——烈日、泥水、断骨；再看看书吏，他坐在阴凉处，手上只有笔和纸。结论是：**去做书吏吧。**

这份文本今天读起来像招生广告，其实是一份阶级说明书。它说明了一件事：**书吏的地位不来自他写得好，来自"只有他能写"。**

美索不达米亚的书吏在"泥板屋"（edubba）里受训，学的是楔形文字的数百个符号和一套公式化的文书格式。中国的"史"是一个官职，甲骨上就有"史"字，后世演为太史、御史。玛雅的书记由贵族子弟担任。四地相隔万里，位置却完全一样：**站在记录与权力之间。**

这一级的生意有个特点：**它不是市场生意，是俸禄生意。** 书吏拿的是国家的粮食、份地或者地位，不是按字计酬的稿费。原因很简单——文字的主要用途是记账、收税、立法、占卜，雇主只有一个，就是国家和神庙。

所以这一级的"公司"形态是国家机关。它带来一个后果，一直延续到今天：**谁出钱，谁决定什么被记下来。** 王室的功绩刻在石碑上，平民的债务记在泥板上，两者都不由"作者"自己选择。

写作作为一门可以卖钱的手艺，还要等一千年——等到写字的人不必是官，而要等买书的人多起来。

## 四、窟窿的另一面：写下来的就"是真的"

还有一个更微妙的后果。

口传说错，听的人可以质疑："我爷爷说的不是这样。" 白纸黑字写错，质疑就难得多。文字自带一种权威感——它看起来是中立的、客观的、不带情绪的。所以**错误一旦被写下来，就获得了免于质疑的特权。**

中世纪的抄写员抄错一个数字，这个错误会被下一代的抄写员忠实继承，再被引用、再被当作依据。等到有人发现不对，已经错了两百年，而且"古书上是这么写的"。

文字的第二个窟窿，和第一个正好相反：它不光让人拿不到信息，它还让人**太容易相信手上的信息**。

## 本章的逻辑

**上一级最贵的是什么？** 记忆。经验只能存在人脑里，人一死，经验就断；口传会漂移，无法跨代稳定积累。

**突破在哪？** 约公元前 3200 年，两河流域出现成体系的文字（楔形文字），起源是记账。埃及圣书体大致同时。中国的甲骨文出现在商代晚期（约公元前 1300 年），已是相当成熟的系统，说明它在此之前已经历了漫长演化。

**成本降了几个数量级？** 就"留存"而言，是从"几代"到"几千年"，跨度不是数量级，是**量纲的改变**。但就"获取"而言，成本几乎没降——文字反而让绝大多数人彻底读不到信息。

**释放了什么协同？** 跨代积累、契约与长期交易、官僚制国家、成文法典、可追溯的责任。人类第一次有了"历史"这种东西——不是因为那时的人更爱记事，是因为那时才有东西能记事。

**留下什么新窟窿？** 两个。第一，**复制**：文字存住了，但一本书要几个月才能多出一本，知识被锁在极少数人手里。第二，**可信**：写下来的东西自带权威，错误因此可以稳定地传两千年。

下一个台阶，要把第一个窟窿堵上：让拷贝变便宜。
