# 隐线：科技浪潮的底层逻辑

**The Hidden Thread: The Underlying Logic of Technological Waves**

> 表面上，技术史是一堆互不相干的发明；底下有一条几乎没人明说的线——人类一直在跟信息的三种成本较劲：**传出去（距离）、留下来（时间）、看得懂（理解）**。每一级台阶，都是在补上一级没补上的窟窿。

## 书名

中文：**《隐线：科技浪潮的底层逻辑》**

目录名用英文书名的连字符形式。

三重"隐"：一，它不在任何一台机器上，而在机器之间（拆开一台电报机找不到"距离被压缩"）；二，它在起作用时最不显眼（技术成功之后就不再被当作技术，而变成背景）；三，它不在任何一本书的目录里（领域分类把这条线切碎了）。它之所以值得被看见，是因为它解释了"为什么这些发明出现的顺序不是随机的"。

## 六条定律

1. **瓶颈迁移律**——技术不消灭瓶颈，它把瓶颈搬到下一环。
2. **数量级律**——只有把某项成本压下一个数量级才算革命，压 10% 只是生意。
3. **协同跃迁律**——成本每降一个数量级，可协同的规模与复杂度上一个台阶。
4. **旧技术不死律**——旧技术不消失，它退到最擅长的窄场景里继续活。
5. **稀缺转移律**——成本归零的那一环不再稀缺，稀缺性顺着链条往后移：传 → 存 → 分发 → 处理 → 理解 → 验证。
6. **加速器律**——资本不改变技术的方向，只改变技术的速度（同时开十条路，错九条）；企业家是资本与技术之间的翻译。越靠近物理极限，资本能加速的越少，只剩耐心。

## 尾声的落点

前五次脱钩都发生在外部：距离（电报）、人数（广播）、份数（互联网）、在场（移动互联网）、阅读量（大模型）。

尾声把镜头拉远，指出链条上唯一没被压下去的一项：**生命本身的时间**。信息速度两百年提了两个数量级，运输速度两百年也提了两个数量级，而人类的最大寿命一千年只挪了不到 10%。按瓶颈迁移律，它必然是下一个战场；按同一条规律，它也必然留下新窟窿（年龄结构、分配、意义）。

## 体例

- 每章收尾一节「本章的逻辑」，把该级台阶拆成五问：上一级最贵的是什么 → 突破在哪年 → 成本降了几个数量级 → 释放了什么协同 → 留下什么新窟窿。
- **商业分两层**：第 1–13 章每章末尾有「钱在这一级」，用一个人或一家公司回答"钱凭什么流到那一环"（格里奥、书吏、佣书、出版商、西联/路透、AT&T、RCA、IBM、谷歌、苹果/高通、Netflix、排序者、英伟达）；第 14 章不介绍公司，只把十三个位置并排，提炼四条规律（收钱方式四次叠加、行业形状由算术定、在位者资产即负担、发明者/整合者/卡位者）。
- **两条横切线的分工**：第 14 章问"钱怎么赚"（产业内的利润分配），第 15 章问"钱怎么来"（资本如何把三十年的路压成五年，企业家如何在中间做翻译）。两章末尾都指向"谁在承担不确定性"。
- 史实尽量给年份与可核查的量级；有争议的逸事明确标注为「流传的说法」。
- 引用与延伸阅读集中于附录 B，共 43 种（含熊彼特、马拉比、马祖卡托三种资本类），逐一注明与本书的关系。
